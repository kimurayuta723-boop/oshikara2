# 推しカラ

家カラオケ用の、スマホを振って鳴らすうちわ・メロイックサイン・ペンライトのWebアプリです。
みんなで一緒に振るほど打楽器の音が大きく、にぎやかになります。

## 遊び方

1. 1人が「ルームを作る」を押し、ROOMボタンでQRコードを出す。ほかの人はカメラで読み取るか、4桁の部屋コードを入れて参加する
2. 自分の色を選ぶ(色ごとに打楽器の音が変わる)
3. うちわ・メロイック・ペンライトから選んで「掲げる」
   - **振る**:自分の色の打楽器が鳴り、画面が光る。0.6秒以内に一緒に振った人が多いほど音が大きくなり、3人以上で手拍子、全員そろうとシンバル
   - **強く振る**:低い「ドン」が加わったアクセント
   - **手首をひねる**:シャカシャカ(シェイカーのロール)
   - **6回以上続けて振ってから止める**:締めの「ジャン!」
   - **一定のテンポで振り続ける**:フチの光がだんだん強くなり、最後は虹色になる(点数はなし)
   - **下ろす**:うちわ・メロイックは縦に戻すか寝かせる、ペンライトは寝かせると作る画面に戻る

## 公開(GitHub Pages)

ビルドは不要です。リポジトリの Settings → Pages で `main` ブランチの `/(root)` を公開してください。
振る動きの検知はHTTPSでしか動かないため、GitHub PagesのURLで開いてください。

## しくみ

- 通信はPeerJS(WebRTC)を使い、ルームを作った人のスマホが中継役になります。そのため専用サーバーは不要です
- 音はすべてWeb Audioで合成しているので、音源ファイルはありません
- 振る・掲げる・下ろすの判定は `js/motion.js` の `TUNING` で調整できます

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `js/app.js` | ルーム、うちわ・メロイック、振る・下ろす |
| `js/net.js` | PeerJSでの接続 |
| `js/motion.js` | 振る・掲げる・下ろすの判定 |
| `js/sound.js` | 打楽器の音とシンクロ |
| `js/qr.js` | 招待用QRコードの生成(ライブラリなし) |

## 注意点

- ルームを作った人がアプリを閉じたり画面を消したりすると、ルームが終わります(画面が消えにくい設定は入れています)
- 接続にはPeerJSの無料の公開サーバーを使っています。携帯回線の組み合わせによってはつながらないことがあります
- iPhoneはマナーモードだと音が出ない場合があります
- 掲げたときに文字が逆さまになる端末では、メニューの「掲げたときの文字の向きを反転」で直せます
