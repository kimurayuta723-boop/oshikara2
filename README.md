# 推しカラ

振るだけで鳴る、おうちカラオケの応援グッズです。
スマホがうちわ・メロイックサイン・ペンライトになり、振ると打楽器の音が鳴ります。みんなで一緒に振るほど、音が大きくにぎやかになります。

## 遊び方

1. 1人が「部屋を作る」を押します。左上の「ROOM」を押すとQRコードが出るので、ほかの人はカメラで読み取って参加します。4桁の部屋コードを入力して参加することもできます。
2. 自分の色を選びます。色ごとに鳴る楽器が決まっています。

   | 色 | 楽器 | 色 | 楽器 |
   | --- | --- | --- | --- |
   | ピンク | タンバリン | 黄 | 鈴 |
   | 水色 | マラカス | オレンジ | カバサ |
   | 黄緑 | シェイカー | 赤 | クラップ |
   | 紫 | チャイム | ミント | トライアングル |
3. うちわ・メロイック・ペンライトから1つ選び、「掲げる」(ペンライトは「点ける」)を押して、スマホを掲げます。

### 掲げているときの操作

| 動き | どうなるか |
| --- | --- |
| 振る | 振り切った瞬間に自分の色の楽器が鳴り、画面が光ります。振りの強さに合わせて、音の大きさと明るさ、光の強さが変わります。一緒に振った人が多いほど音が大きくなり、3人以上で手拍子、全員そろうとベルツリー(きらきら流れるチャイム)が加わります |
| 強く振る | フレームドラムの「ドン」が加わり、アクセントになります |
| 手首をひねる | シャカシャカと、シェイカーのような音が鳴ります |
| 続けて振ってから止める | 6回以上続けて振ったあとに止めると、締めの「ジャン!」が鳴ります |
| 同じテンポで振り続ける | フチの光がだんだん強くなり、最後は虹色になります(点数はつきません) |
| 下ろす | うちわ・メロイックは縦に戻すか寝かせる、ペンライトは寝かせると、選ぶ画面に戻ります |
| 長押し | どの状態からでも、選ぶ画面に戻ります |

振る動きを使えない端末では、画面をタップすると音が鳴ります。
反応しにくい・反応しすぎるときは、メニューの「振りの感度」で「敏感/ふつう/にぶめ」を切り替えられます。

## 公開(GitHub Pages)

ビルドは不要です。リポジトリの Settings → Pages で、`main` ブランチの `/(root)` を公開してください。
振る動きの検知はHTTPSでしか動かないため、GitHub PagesのURLで開いてください。

## しくみ

- 通信にはPeerJS(WebRTC)を使い、部屋を作った人のスマホが中継役になります。専用のサーバーは要りません。
- 音はすべてその場で合成しているため、音源ファイルはありません。楽器ごとに「何がぶつかって、どう響くか」をまねています。
  - マラカス・シェイカー・カバサ:中の粒がひとつずつ殻に当たる様子(物理モデル PhISEM)
  - タンバリン:10枚のジングル、鈴:12個の鈴が、それぞれ固有の金属の響きで鳴る(部品は固定なので、毎回同じ楽器に聞こえます)
  - トライアングル・チャイム:金属の棒の倍音の比率・減衰・うなりを再現
  - クラップ:手のひらの間の空気の響きと、何度かに分かれた破裂
  - 仕上げに軽いリバーブをかけています
- 仕上げに低音カット・コンプレッサー・ソフトクリップを通し、スマホのスピーカーで出せる上限近くまで音量を上げています(割れないよう、上限まで約1dBの余裕を残しています)。端末の音量ボタンも最大にしてください。
- 振る・掲げる・下ろすの判定は、`js/motion.js` の `TUNING` で調整できます。

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `js/app.js` | 部屋、グッズの選択、振る・下ろすの処理 |
| `js/net.js` | PeerJSでの接続 |
| `js/motion.js` | 振る・ひねる・掲げる・下ろすの判定 |
| `js/sound.js` | 打楽器の音とシンクロ |
| `js/qr.js` | 招待用QRコードの生成(ライブラリなし) |

## 注意点

- 部屋を作った人がアプリを閉じると、部屋も終わります。使っている間は画面が消えないようにしています。
- 接続にはPeerJSの無料の公開サーバーを使っています。回線の組み合わせによっては、つながらないことがあります。
- iPhoneはマナーモードのままだと音が鳴らない場合があります。
- 掲げたときに文字が逆さまになる場合は、メニューの「掲げたときの文字の上下を反転する」で直せます。
